NITA Payment Provider

Accept MyNITA wallet payments on your Odoo shop and invoices

NITA Transfert is a money transfer and mobile wallet service. This module adds NITA as a payment provider in Odoo: your customer chooses NITA at checkout, is redirected to the secure NITA payment page, pays from a MyNITA wallet, and comes back to your shop. The order or invoice is then confirmed automatically.

How it works

  • The customer selects NITA and enters a MyNITA number.
  • Odoo creates the purchase at NITA and redirects to the NITA payment page.
  • After payment, the customer returns to your shop. The transaction is confirmed only after Odoo has read the real payment status from the NITA API.
  • A scheduled job reconciles pending payments, so a lost notification never leaves a paid order unconfirmed.

Built for safety

  • Notifications are never trusted: the payment status always comes from the authenticated NITA API.
  • Amount check: a transaction whose amount changed after the payment request is never confirmed automatically.
  • API requests are signed (HMAC-SHA256). Credentials are visible to administrators only.
  • Test mode with the NITA sandbox before going live.

Requirements

  • Odoo 17.0, self-hosted or Odoo.sh. Not available on Odoo Online, because a Python package is required.
  • Python package nita-transfert-sdk, version 0.1.0b2 or later, installed in the Odoo environment.
  • A NITA partner account with the Online Purchase product. The API key, login, password and HMAC secret are in your NITA developer space.
  • Shop currency: CFA franc, XOF (Niger) or XAF (Chad).

Setup

  1. Install the Python package, then install this module.
  2. Open Invoicing, Configuration, Payment Providers, then NITA.
  3. Enter the API base URL and your credentials, then enable the provider, in Test mode first.
